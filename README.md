# Pixel Gacha

Pixel Gacha is a small game/pixel art editor built with [MonoGame](https://monogame.net/). It's a pixel art drawing app based on a gacha card pack economy. You paint on the canvas, earn in-game currency, and with that currency you can buy packs to unlock to new colors and expand your palette.

# Where to play
The game is avaliable on [itch.io](https://crownsheep.itch.io/pixel-gacha) as a web build, so it should work for all operating systems.

## How to use it

| Action | Input |
|---|---|
| Paint a pixel | Left click on the canvas |
| Erase a pixel | Right click on the canvas |
| Pick a paint color | Palette tab in the sidebar → click a swatch |
| Undo last stroke | Undo button in the toolbar above the canvas |
| Clear the canvas | Clear button in the toolbar |
| Save your current art | Save button in the toolbar |
| Browse saved art | Gallery tab in the sidebar → click Load on any entry |
| Open a card pack | Packs tab → select a pack tier → Open Pack |

Start by painting a bit to earn currency, then head to the **Packs** tab once you've saved up enough to open your first pack. New colors will show automatically in your **Palette** and you can use them right away.
